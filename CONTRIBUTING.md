# Source access

This is a maintainer-managed public source repository. Visitors can read, download and fork the source under its licenses; direct write access is not granted to visitors. A pull request cannot change the published branch without a maintainer merging it. Public contributions are not currently promised review or acceptance.

Do not upload personal chats, credentials, model weights, local profiles, build caches or proprietary project files. Preserve upstream and third-party notices. See BUILDING.md before changing packaging.
