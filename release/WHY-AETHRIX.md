# Why Aethrix?

Aethrix combines local Ollama models, a full Code - OSS editor, hardware-aware model installation, deliberate planning/debugging workflows, reviewed file and command tools, persistent chats/queues, and C++/Windows driver helpers. No Aethrix subscription or paid API key is required. It is built around local model choice and existing Windows toolchains. Model licenses, accuracy, speed and memory needs vary. This is a combination of capabilities, not a claim that the individual features are exclusive to Aethrix.

Source, detailed feature descriptions and limitations: https://github.com/zx7-eu/Aethrix
